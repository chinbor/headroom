# 任务栏入口与 Token Plan 订阅

本页描述个人 Fork 新增功能，不代表上游发布包已经包含它们。

## 程序形态

这个 Fork 只保留任务栏组件：任务栏摘要、托盘图标和点击后弹出的“额度与消耗”窗口。原项目的完整面板、紧凑视图、命令行、数据同步、自动更新等功能已删除；本机日志统计和各平台额度读取逻辑保留。

**任务栏摘要（实验性，默认开启）。**在托盘左边的空白处显示两部分：左边是最需要关注的一项，分两行（如上行 `Agnes 周 28%`，下行 `预计 1天13时后用完`）；右边是其他平台各一个小圆环，环内是平台图标，弧长是该平台最紧的剩余比例，颜色表示充足、偏紧、告急。最需要关注的一项这样选：先看按当前速度会在重置前用完的窗口，取最早用完的；没有的话取剩余最低的窗口或余额。宽度上限约 320 物理像素，放不下时先减少圆环，再去掉左边两行，只留圆环。

- 悬停在摘要上约 0.35 秒会弹出浮窗：顶部是一句总结，下面每个平台一行，列出各窗口的剩余、迷你进度条、预计用完时间和余额；鼠标移开就收起。浮窗不抢焦点、不挡点击，单击摘要仍然打开详情窗口，右键是更多操作。

- 告警统一打分：额度窗口按剩余百分比；余额按“余额 ÷ 告警线 × 20”，告警线默认 5，可在设置里改（0 关闭余额告警）。低于 20 为告急，低于 40 为偏紧。
- 颜色跟随任务栏：每 2 秒取摘要左侧几个像素的中位色作背景，按亮度自动换深色或浅色文字，分隔线和圆环底色由背景色混出，浅色、深色、强调色任务栏都能看清。
- 提醒：某个窗口或余额刚变成告急，或按当前速度 1 小时内会用完时，右下角弹出一张提醒卡片。卡片列出平台、窗口、剩余和原因（如 `29 分钟后重置，照现在的速度撑得到`、`预计 26 分钟后用完，4 小时后才重置`），最多 3 项。卡片不抢焦点，15 秒后自动收起（鼠标停在上面时不收），可以点“查看详情”或“1 小时内不再提醒”。同一项恢复之前不重复提醒，“快用完”后真正变成告急会再提醒一次。设置 → 提醒里可以改成系统通知或关闭，也可以预览。
- 实现：挂在 `Shell_TrayWnd` 下、带 `WS_EX_LAYERED` 的子窗口，不注入 Explorer，也不是系统预留的空间；空间不足、任务栏隐藏或前台全屏时自动移除。Win11 任务栏走 DirectComposition 合成，普通子窗口不显示，必须带 `WS_EX_LAYERED`（程序清单声明 Win8 及以上）；挂在 `DesktopWindowContentBridge` 下收不到点击，所以直接挂在 `Shell_TrayWnd` 下。

**额度与消耗窗口。**单击摘要或托盘图标，在屏幕中央打开（再点一次或按 Esc 关闭），分三页：

- **额度**：顶部一句话结论（几项需要注意、哪个窗口按当前速度最先用完）和更新时间；下面是今日 / 近 7 天 / 近 30 天三张数字卡片（token、API 等价费用、与前 7 日均值对比、每日走势线）。平台卡片分“需要注意”和“正常”两组，每个窗口显示剩余百分比、已用 / 上限、多久后重置，进度条上的竖线是按时间均匀使用、此刻应剩的位置，下面一行是按当前速度的预计（如“预计 38 分钟后用完”）；读数过时的卡片变淡并标出上次成功时间。
- **消耗**：可切换 Token / 费用，范围 7 天或 30 天。从上到下依次是：
  - 五个数字卡片：Token（含日均）、API 等价费用、请求数（每次约多少 token）、缓存命中率（输入中来自缓存读取的比例）、输出速度（有计时的请求平均 tok/s）。日志里没有的项显示“—”。
  - 按平台堆叠的每日柱状图：悬停看当天各平台明细，点图例可以隐藏或显示某个平台。
  - 按平台表格：Token 和占比、API 等价费用、请求、缓存命中、常用模型；点一行展开模型拆分（最多 8 个）。
  - “几点用得最多”：24 格热力条，按本地时间统计每小时的 token，标出高峰时段，数据来自本机日志的按小时索引。
  - DeepSeek 实际扣费（人民币）：和 API 等价费用分开显示。
  - 原来的“余量”子页和额度页重复，已删除。
- **设置**：订阅管理、余额告警线、任务栏摘要开关等。

## 支持的平台与接入方式

目前只提供 Claude、Codex、DeepSeek、Agnes 四个平台（其他平台的读取代码还在源码里，但不再出现在设置中）。

| 平台 | 怎么接入 | 读到的内容 |
| --- | --- | --- |
| Claude | 用 Claude Code 登录即可 | 5 小时 / 每周额度；token 和费用来自本机日志 |
| Codex | 用 Codex 应用或 CLI 登录即可 | 5 小时 / 每周额度；token 和费用来自本机日志 |
| DeepSeek | 设置 → 订阅 →「登录添加」，在弹出的网页里登录；或点「用 API Key」只读余额 | 钱包余额（充值 + 赠送）、最近 30 天每天每个模型的 token 和请求数（按官方价格折算 API 等价费用） |
| Agnes | 设置 → 订阅 →「登录添加」，在弹出的网页里登录 | 文本 5 小时 / 每周、图像 / 视频每日套餐额度，最近 30 天每天的文本 token 和请求数 |

DeepSeek 和 Agnes 都由“接入方案”描述（`platforms/deepseek.json`、`platforms/agnes.json`），添加其他平台也是写一个方案，见 [平台接入方案](./platform-recipes.md)。

**网页登录。**添加 DeepSeek / Agnes，或登录过期点“重新登录”时，程序用内置的 WebView2 打开平台控制台；你在页面里正常登录，程序每秒执行一次接入方案里的 `token.read` 脚本读取登录信息，验证成功后自动保存并关闭窗口。WebView2 不可用时可以点“改用手动方式”，按 4 步引导从浏览器控制台复制 token。WebView2 的数据放在 `data/webview2`，HTTP 缓存上限 10 MB，关闭登录窗口后清掉页面缓存，只保留 cookie 和本地存储。token 是网页控制台的登录凭据，不是 API Key；在网页上退出登录或过期后会失效，到时设置页和卡片会提示重新获取。

- 平台控制台的每日用量会代替本机日志对这个平台的统计（控制台已包含其他电脑和其他工具的请求，DeepSeek Harness 的用量也在其中，不会重复计算）。用量读取失败时保留上次的数据。
- Agnes 是包月套餐，没有按 token 的价格，费用记为未知，汇总里的费用显示为下限（`≥`）。
- 这两个平台用的都是网页控制台的内部接口，没有公开文档，平台改版可能失效。
- token 用 Windows DPAPI 加密保存在本机，只发给方案里写的地址（`platform.deepseek.com`、`platform-backend.agnes-ai.cn`）。

**从旧版本升级。**第一次启动时自动迁移：旧的「添加 Agnes」自定义订阅换成内置 Agnes，平台 token 一并转过去；DeepSeek 原来可选的平台 token 变成它唯一的凭据。原来填的 DeepSeek API Key（`sk-` 开头）用不上了，移到 `data/deepseek-apikey.key` 保留，不删除。Agnes 的邮箱密码自动登录（`AGNES_EMAIL` / `AGNES_PASSWORD`）已不再支持。

## DeepSeek 实际扣费（按余额变化）

每次读到 DeepSeek 余额时记下读数（`data/balance-ledger.json`）：余额下降算当天扣费，上升视为充值，只更新基准。DeepSeek 卡片和消耗页显示“实际扣费：今日 / 7 天 / 30 天”，单位是账户币种（人民币），不折算美元，和 API 等价费用分开。

限制：从程序第一次读到余额那天开始记录，之前的扣费没有；两次读数之间又充值又消费会互相抵消，所以是下限；程序没开的时间段，扣费会记到下一次读数那天。

## Agnes 额度含义

| 名称 | 来源 | 含义 |
| --- | --- | --- |
| 文本 · 5 小时 | `usage.text_generation.windowed` | 文本短周期套餐额度 |
| 文本 · 每周 | `usage.text_generation.weekly` | 文本周额度 |
| 图像 · 每日 | `usage.image_generation.daily` | 图像日额度 |
| 视频 · 每日 | `usage.video_generation.daily` | 视频日额度 |

优先使用接口的 `usage_pct`，否则用 `used / limit` 算已用比例，界面统一显示**剩余百分比**，同时显示“已用 / 上限”。相对重置秒数转为绝对重置时间；缺失使用量不伪造为 0，零配额显示剩余 0%。无可识别窗口时显示错误，不显示虚假充足状态。这些是套餐窗口额度，不是现金余额或已付账单。

## 构建与安全演示

在仓库根目录运行：

```powershell
.\source\Windows\build.ps1 -OutputDirectory .\artifacts\dev
.\artifacts\dev\codeusagemonit.exe --demo
```

演示使用虚构的四个平台数据，不查询真实账户，不导入插件凭据，不保存设置。普通模式会执行原项目的本机账户／日志读取逻辑；未经确认不要用普通模式验证真实账户。

自测（图形程序，等待进程退出后读取结果）：

```powershell
$p = Start-Process .\artifacts\dev\codeusagemonit.exe -ArgumentList '--self-test' -Wait -PassThru
$p.ExitCode
Get-Content .\artifacts\dev\verification\tests.json
```

2026-10-31 已验证：编译通过，109 项自测全部通过（含余额记账：首次读数作基准、下降算扣费、上升算充值、40 天外清理）；演示模式下 DeepSeek 卡片的实际扣费显示正常；在本机（Windows 11 25H2，2560×1440，深色任务栏）用演示模式实测紧凑摘要、点击开关居中窗口、三个页面和各图表，以及任务栏两行摘要、圆环、悬停浮窗、提醒卡片和消耗页（深色与浅色主题，提醒卡片的“查看详情”能打开详情窗口）。DeepSeek 与 Agnes 的用量接口在已登录的浏览器里实测过返回结构；DeepSeek 接口从非浏览器客户端也能访问（未被 WAF 拦截）。

尚未验证：程序用真实平台 token 的完整拉取、旧配置的自动迁移、浅色和强调色任务栏、Explorer 重启、自动隐藏任务栏、多显示器和不同 DPI、托盘通知的实际样子。其他 Windows 版本和第三方任务栏不作兼容性承诺。
