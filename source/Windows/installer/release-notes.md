# 余量 Headroom __VERSION__

## 本版更新

__CHANGES__

## 简介

常驻 Windows 11 任务栏的 AI 订阅额度小组件：Claude、Codex、DeepSeek、Agnes 还剩多少、什么时候重置、照现在的速度会不会提前用完，瞄一眼任务栏就知道。

## 下载

- **headroom-setup-__VERSION__.exe**：安装程序。不需要管理员权限，默认装到 `%LOCALAPPDATA%\Programs\余量 Headroom`，可选桌面快捷方式和开机启动。在“Windows 设置 → 应用”里卸载，卸载前会询问是否删除设置。
- **headroom-__VERSION__-win-x64.zip**：免安装。解压到可写的文件夹后运行 `headroom.exe`，数据在旁边的 `data` 文件夹。
- **SHA256SUMS.txt**：两个文件的 SHA-256 校验值。

程序没有代码签名，SmartScreen 提示时选“更多信息 → 仍要运行”。使用说明见压缩包里的 `使用说明.md`。
